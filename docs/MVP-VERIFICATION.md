# Проверка MVP — 22 сентября 2026

- Основной интерфейс упрощён: каталог и калькуляция исключены из создания заказа; старые таблицы и исторические цены сохранены.
- Миграция `simple_order_mvp` разрешает публикацию и подтверждение товаров с `price = null`, не ослабляя ownership-проверки и валидацию количества.
- Миграция применена в Supabase; `buyer-public-order` развёрнута, версия 4.
- Живой SQL-тест проверил draft → waiting → received → ordered → completed и сохранение null-цены. Тест выполнен с rollback и не оставил тестовых заказов.
- Локальные тесты проверяют изоляцию двух байеров, отказ anon в прямом чтении, запрет чужих товаров, повторное подтверждение и ошибки уведомлений.
- Telegram отключён до настройки трёх секретов; внешняя отправка не проверялась.
- Supabase Security Advisors не сообщил замечаний для объектов `buyer_*`. В общей базе остаются замечания по не относящимся к Bayer функциям и настройкам: [доступ authenticated к SECURITY DEFINER](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable), [restore_history без политик](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy), [отключённая проверка утекших паролей](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection). Они не изменялись в этом задании.

Архивный `AUDIT.md` описывает расширенную версию от 20 сентября, а не текущий интерфейс MVP.

## Результаты

- `npm run check`: lint, TypeScript и тесты прошли; после добавления Telegram-тестов — 13/13, повторный lint тоже прошёл.
- `npm run test:e2e`: 10/10 (desktop + mobile).
- `npm run build -- --webpack`: production-сборка прошла. Turbopack в этой среде не смог открыть свой служебный порт (`EPERM`), поэтому использован официальный webpack-флаг без изменения исходников.
- Живой публичный API после развёртывания возвращает HTTP 404 для неверного токена.


## Обновление дизайна и восстановление расчёта

По уточнению пользователя восстановлен исходный расчёт без изменения `lib/pricing.ts`: CNY × 1,4 + 30 TJS/кг + работа, вес по умолчанию 80 г. Он работает при создании и редактировании товаров. UI использует общий компонент расчёта, который показывает составляющие цены.

Добавлены общие параметры с отменой, системное меню «Поделиться» с копированием как запасным вариантом, поиск и серверная пагинация. Кеш подписанных фото ограничен экземпляром страницы; проверено, что повторное чтение не создаёт запрос, а истечение срока обновляет только нужный путь. Формулы и существующие опубликованные цены не менялись.

Финальные результаты обновления: 14 unit/API/PostgreSQL тестов, 12 браузерных сценариев desktop/mobile. После исправления положения мобильной навигации целевые 2 сценария повторены успешно. Визуально проверены desktop/mobile список и редактор; тест проверяет отсутствие горизонтального переполнения, положение мобильной навигации и фактическую загрузку фото. Формула проверена на создании (57,1 смн) и редактировании (80 смн).
